# FastNear Go v1.0.1

This release fixes the Go version mismatch in CI, updates the SDK version to
1.0.1, and includes the HTTP, RPC, pagination and amount-handling improvements
documented in the changelog.

## Highlights

- Test Go 1.23, 1.24 and 1.25; read the minimum Go version from `go.mod` for lint
  and coverage jobs instead of using unsupported Go 1.21.
- Apply connection timeouts and preserve redirect restrictions with custom HTTP
  clients. Keep credentials out of SDK errors and logs.
- Honor retry settings for RPC failures and transaction submission, and report
  aggregate transaction execution status, including receipt failures.
- Correct RPC response decoding, exact amount formatting, continuation cursors
  and malformed timestamp handling.
- Expand the README with practical examples, configuration details and SDK
  limitations. Correct the Go Reference badge.

## Compatibility note

The transfer history response type is now `transfers.Page`. Replace explicit
references to `transfers.TransfersPage` in your code. Calls that use type
inference, such as `page, err := client.Transfers().Query(ctx, query)`, do not
need a type-name change.

## Requirements and installation

Go 1.23 or later is required. The SDK uses only the Go standard library.

```sh
go get github.com/tigusigalpa/fastnear-go@v1.0.1
```

Transaction signing remains outside the SDK: submission methods accept already
signed transactions. Live FastNear availability and indexing limits are
controlled by the upstream services.
